25|## 已定的技术决策
26|
27|1. **按 prompt_id 分组做 CV**。2,699 条 = 150 prompt × 18 模型，随机切分会让同 prompt 泄漏进验证集，CV 虚高。
28|2. **主模型：Qwen3-8B + 4-bit QLoRA + 18 类分类头**。只取前 512 token，原始段落直接分词，不加问答模板。
29|3. **外部数据要进主配方，但必须做对照**：同折、同更新步数下「12 官方 + 4 外部」vs「16 官方 + 0 外部」。

49|## 已知的坑
50|
51|- `Qwen3ForSequenceClassification` 需要 **transformers ≥ 4.51**，否则只能 `AutoModel` + 手写 score 头。
52|- `add_special_tokens=False` 遇到空文本会得到 0 token 直接崩 → `text or " "` 兜底。

54|- P100 是 Pascal：无 bf16、无 tensor core，`compute_dtype` 只能 fp16；bitsandbytes 4-bit 可用但慢。
55|- 测试集 public 40% / private 60%，且每类条数不等、公私混合比例不同 → 别按 public 排名调参。
